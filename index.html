엑셀·구글 시트의 셀을 붙여넣거나 PDF를 불러오면 고해상도 PNG로 저장할 수 있어요. 폰트·이미지·셀 크기를 정확히 유지하려면 PDF 방식을 추천합니다.
셀 범위 붙여넣기
이 칸을 누르고 Ctrl+V
모바일에서는 길게 눌러 ‘붙여넣기’
모바일에서 복사가 잘 안 될 때 사용하는 버튼이에요
간단한 사용 방법
  1. 정확한 서식이 중요하면 시트 앱에서 PDF로 내보낸 뒤 ‘PDF 파일 불러오기’를 누르세요.
  2. 필요한 페이지와 연결 방향을 고르고, 중복된 경계는 제거 픽셀을 조절해 맞춰 주세요.
  3. ‘경계 부분 보기’로 연결 부위를 확인한 뒤 해상도·배경·여백을 정하고 PNG로 저장하세요.
  4. 간단한 표는 셀 범위를 복사해 왼쪽 칸에 바로 붙여넣어도 돼요.
